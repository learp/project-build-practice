# build-practice — практика к лекции «От кода к исполняемому файлу: Сборка проектов»

Четыре проекта — одно и то же консольное приложение **log-stats, анализатор
логов**, собранное четырьмя способами. Смысл: меняется не ЧТО мы собираем,
а КАК. Легенда: «коллега прислал лог прод-сервиса и просит понять, что
там происходит» — вход везде одинаковый, `samples/app.log`, реальный кусок
лога signaler'а веб-звонков.

| Директория   | Способ сборки            | Слайд практики | Что почувствуем                        |
|--------------|--------------------------|----------------|----------------------------------------|
| `00-manual/` | Никакой: javac + classpath | 4–8          | «Так жить нельзя»                      |
| `01-maven/`  | Maven                    | 30             | «Одна команда — и всё само»            |
| `02-gradle/` | Gradle                   | 52             | «То же, но быстрее и гибче»            |
| `03-cmake/`  | CMake (C++)              | 62             | «Другой мир: компилируемые языки»      |

Порядок именно такой: сначала боль (`00-manual`), потом лекарства.
Каждая директория самодостаточна — начните с её README.

## Общий технический baseline

- Java 21+, Maven 3.9 (wrapper), Gradle 9.2.1 (wrapper), CMake 3.28+
